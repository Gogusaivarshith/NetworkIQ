# NetworkIQ - AI Supply Chain Intelligence Platform

## Overview

NetworkIQ is an AI-powered Supply Chain Analytics platform built during a hackathon. It analyzes sales and inventory data to provide business insights, inventory optimization, demand forecasting, and AI-driven transfer recommendations.

---

## Features

- Dashboard with KPI metrics
- Sales Analytics
- Inventory Analytics
- Demand Forecasting
- AI-based Inventory Transfer Recommendations
- Interactive Charts using Recharts
- FastAPI REST Backend
- React + TypeScript Frontend
